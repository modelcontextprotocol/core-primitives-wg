# Meetings

Find upcoming calls on the
[Core Primitives WG calendar](https://meet.modelcontextprotocol.io/tag/core-primitives-wg)
and coordinate agenda items in `#core-primitives-wg` on
[MCP Discord](https://discord.com/invite/6CSzBmMkjX).

Follow the shared [meeting requirements](https://modelcontextprotocol.io/community/working-interest-groups#meetings-and-channels).
Publish agendas and notes in the MCP repository's
[Meeting Notes discussions](https://github.com/modelcontextprotocol/modelcontextprotocol/discussions/categories/meeting-notes-other).
Agendas should link to the [MCP Project Policies](https://modelcontextprotocol.io/community/policies).

Use this directory for summaries and action items, named `YYYY-MM-DD_weekly.md`.
Link each summary to the public agenda and notes discussion, and include
decisions, action owners, and relevant issues or proposals.
