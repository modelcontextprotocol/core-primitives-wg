# MCP Core Primitives Working Group

The **MCP Core Primitives Working Group** coordinates improvements to the core
primitives in the [Model Context Protocol (MCP)](https://modelcontextprotocol.io),
including tool results, discovery, and annotations.

## Mission

Our initial focus follows the **Improved Primitives** priority area in the
[MCP roadmap](https://modelcontextprotocol.io/development/roadmap#4-improved-primitives):

- **Tool result shape** — Make structured and unstructured tool results easier
  for clients and servers to handle consistently.
- **Progressive discovery** — Let clients discover the tools and resources they
  need without loading the full catalog up front.
- **Primitive annotations** — Clarify the purpose and handling of content
  annotations, including audience and priority.

See our [roadmap](./roadmaps/README.md) for the initial work areas and related
coordination.

## Getting Involved

We welcome contributions from anyone interested in MCP core primitives:

1. **Join the community** — Connect on the `#core-primitives-wg` channel in
   [MCP Discord](https://discord.com/invite/6CSzBmMkjX).
2. **Attend meetings** — Find upcoming calls on the
   [Core Primitives WG calendar](https://meet.modelcontextprotocol.io/tag/core-primitives-wg).
   Meetings are open to all community participants.
3. **Contribute** — Open issues to describe problems and use cases, review
   proposals, or submit pull requests.

Keep related material together under `proposals/<project>/`, using descriptive
filenames and `XXXX-` prefixes for draft SEPs. Include authors, status, and
discussion links. When work moves upstream, link to the official SEP and mark the
local draft as historical. Follow the
[MCP SEP guidelines](https://modelcontextprotocol.io/community/sep-guidelines)
for the formal proposal process, including WG discussion and approval before
opening an upstream SEP pull request.

All participants must follow the
[MCP Code of Conduct](https://github.com/modelcontextprotocol/.github/blob/main/CODE_OF_CONDUCT.md)
and the
[MCP Antitrust Policy](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/ANTITRUST.md).

See [GOVERNANCE.md](./GOVERNANCE.md) for governance policies, members, and working
group leads.
