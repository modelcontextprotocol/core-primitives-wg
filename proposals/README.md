# Proposals

Keep each project's problem statement, proposal drafts, supporting research, and
decision records together under `proposals/<project>/`.

Start with an issue describing the problem and concrete use cases. Use
descriptive filenames such as `problem-statement.md` and `XXXX-tool-results.md`
for a draft SEP. Include authors, status, and links to the relevant discussion.

Follow the [MCP SEP guidelines](https://modelcontextprotocol.io/community/sep-guidelines)
when preparing a formal proposal. Record WG discussion and approval before
opening an upstream SEP pull request. Once a proposal moves upstream, link to the
official SEP and mark the local draft as historical.
